# Security policy

## Supported versions

Security fixes are applied to the current `main` branch. No released production
service or long-term-support version is represented by this repository yet.

## Report a vulnerability

Do not place credentials, exploit details, personal data, or sensitive customer
information in a public issue. Use GitHub's private vulnerability reporting for
this repository when it is enabled. If it is unavailable, contact the repository
owner through a previously verified private channel and request a secure intake
method before sending technical details.

Include the affected commit, component, reproduction conditions, impact, and a
safe way to confirm the issue. Receipt or remediation timing is not guaranteed
until a formal support policy is published.

## Operating boundary

Watch-Dawg is for defensive use on public data or systems and files owned by, or
contractually authorized to, the operator. Do not use it to guess credentials,
exploit services, evade controls, establish persistence, or change financial
records without a reviewed plan and explicit human approval.
